# Implementation Report

## When to Use

- 実装完了後に人へ報告を返すとき
- 軽微な設計変更や既存挙動への影響を明示したいとき
- 未確認事項や残余リスクを整理したいとき

## Required Inputs

- 実装したタスク
- 変更したファイルや主要差分
- 実施した確認内容
- 未確認事項や懸念点

## Procedure

1. 実装した内容を、タスク目的と対応づけて整理する。
2. 変更ファイル、設計判断、軽微な設計変更の有無、既存挙動への影響を明示する。
3. 実施した検証と、その範囲外に残るリスクを分けて書く。
4. 文書を移動した場合は、移動元、移動先、理由を明記する。
5. 永続化が必要な場合のみ docs/.ai-works に報告文書を残す。

## Output

- 変更内容
- 変更したファイル
- 設計判断
- 軽微な設計変更の有無
- 既存挙動への影響
- 確認したこと
- 未確認とリスク
